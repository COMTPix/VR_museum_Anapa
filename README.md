# VR Музей "Крепость Анапа"

## 📋 Описание проекта

VR Музей — это интерактивная виртуальная галерея, посвящённая истории крепости Анапа и Русско-турецких войн. Проект позволяет посетителям погрузиться в мир истории через технологию виртуальной реальности.

## 🎯 Функционал

### Главная страница (index.html)
- Приветственный экран с информацией о музее
- Навигационное меню с ссылками на разделы
- Карточки с описанием возможностей музея
- Адаптивный дизайн для всех устройств

### VR Галерея (vr_gallery.html)
- Полноценная 3D-галерея на базе A-Frame
- Интерактивные картины с описанием
- Поддержка VR-шлемов
- Навигация с помощью клавиатуры (WASD) и мыши
- Кнопка возврата на главную страницу

## 🖼️ Коллекция

В музее представлены:
- Картины Василия Верещагина ("После атаки. Перевязочный пункт под Плевной")
- Исторические фотографии памятников Анапы
- Информационные стенды о художниках и исторических событиях

## 🚀 Запуск проекта

1. Откройте файл `index.html` в любом современном браузере
2. Для просмотра VR-галереи нажмите кнопку "🎨 Посетить галерею"
3. Используйте мышь для обзора и клавиши WASD для перемещения

## 🛠️ Технологии

- **HTML5** — структура страниц
- **CSS3** — стили и анимации
- **A-Frame 1.5.0** — фреймворк для виртуальной реальности
- **Three.js r158** — 3D-рендеринг

## 📱 Совместимость

- ✅ Desktop браузеры (Chrome, Firefox, Safari, Edge)
- ✅ Мобильные устройства (iOS Safari, Chrome Android)
- ✅ VR-шлемы (Oculus Rift, HTC Vive, Cardboard)

## 🎮 Управление

### В VR-галерее:
- **W, A, S, D** — перемещение
- **Мышь** — обзор по сторонам
- **ЛКМ** — взаимодействие с экспонатами
- **ESC** — выход из режима.pointer lock
